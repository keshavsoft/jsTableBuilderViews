Renderers Guide

TableBuilder uses "Renderers" to draw UI components on the screen. Renderers are stateless components that take normalized data from the core and convert it into HTML.

1. The Vertical Renderer (vertical)

Used primarily for creating forms, filters, and inputs. It reads the unique values from the data store to generate dropdowns and inputs.

{
  "rendererType": "vertical",
  "theme": "light"
}

Key Feature: If a button with the text "Filter" is clicked within a vertical renderer, it automatically intercepts the inputs and triggers the `TableBuilder.filterData()` pipeline.

2. The Table Renderer (table)

Generates a standard HTML data grid. It maps the flattened data keys (from the `columns` array) into rows and columns.

{
  "rendererType": "table",
  "theme": "dark"
}

Integration: Complex data types or editable cells inside the table are handled by injecting Web Components (`KsTableCellContent`).
