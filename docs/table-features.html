Table Features Guide

A consolidated guide explaining how to enable and configure Serial Numbers, Global Search, and Column Filters in TableBuilder.

1. Serial Number Column Guide

TableBuilder supports an automatic Serial Number (#) column as the first column in your data table.

Configuration:

{
  "htmlId": "table-root",
  "showSerialNo": true,
  "data": [...],
  "columns": [...]
}

How It Works Under The Hood:

  • prepareColumns.js: Prepends { header: "#", dataKey: "$serial" } at Index 0.
  • prepareData.js: Maps each row item to include $serial = index + 1.
  • Dynamic Re-indexing: Automatically re-sequences $serial = 1, 2, 3... whenever data is searched or filtered.

2. Global Search Guide

Global Search queries across all visible columns simultaneously using substring matching.

Usage & Method:

tableBuilder.setGlobalSearch("Electronics");

How It Works Under The Hood:

  • searchUtils.js: Implements processSearch() matching queries across all column keys.
  • buildTable/index.js: Renders top search toolbar with input box, Search button, and row badge.

3. Column Filters Guide

Individual column filters render input boxes directly beneath each column header inside <thead>.

Usage & Method:

tableBuilder.setColumnFilter("category", "Electronics");

How It Works Under The Hood:

  • TableHeader.js: buildColumnFilterRow() appends a second header row with input elements.
  • Multi-Column AND Logic: Filters evaluate concurrently so rows match all active column criteria.
