Developer & Internal Architecture Guide

Internal architecture details, engine design, data normalization, and state flow.

Codebase Architecture

1. renderStart/core (Engine)

The brain of the system. TableBuilder.js normalizes input options, holds single source of truth for original and filtered data, tracks DOM nodes, and exposes CDN knowledge methods (describe() & sampleConfig()).

2. renderStart/renderers (UI)

Stateless UI rendering modules (tableRenderer and verticalRenderer) that convert column schemas into pure semantic HTML elements.

Filtering State Flow

  1. User clicks Filter button inside a vertical form renderer.
  2. Renderer invokes button callback, returning line data values to TableBuilder.
  3. TableBuilder.filterData() updates active data store.
  4. RefreshManager.js destroys only the old table DOM node and re-renders the new data grid, keeping vertical form state untouched!
