Configuration Schema

The entire `TableBuilder` UI is driven by a single JSON configuration object passed to the constructor. This document explains the primary keys.

The Root Object

{
  "htmlId": "app-root",
  "data": [...],
  "columns": [...],
  "views": [...]
}
  • htmlId (String): The ID of the DOM element where the app will be rendered.
  • data (Array): An array of JSON objects containing the raw data. The engine flattens nested keys automatically.
  • columns (Array): Defines the schema for mapping data attributes to display headers.
  • views (Array): Defines which UI renderers to use (e.g., vertical filters and data tables).

The Columns Array

Each object in the `columns` array maps a flattened data key to a human-readable column name.

{
  "dataKey": "details.stockitemname",
  "header": "Item Name",
  "options": {
      "sortable": true,
      "width": "150px"
  }
}

Note: Ensure `dataKey` matches exactly how the keys appear in your data after flattening.
