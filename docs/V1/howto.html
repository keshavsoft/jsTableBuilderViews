1. Adding Columns

Add a column definition to the columns array in your JSON config:

{ "dataKey": "order.total", "header": "Total Amount", "options": { "width": "120px" } }

2. Pulling Sample Config from CDN

import { TableBuilder } from "https://keshavsoft.github.io/jsTableBuilderViews/renderStart.js";
const config = TableBuilder.sampleConfig();
config.data = myData;
const builder = new TableBuilder(config);
await builder.build();
