Repository Dependency & Relationship Report

ks-web-components ↗ jsTableBuilderViews ↗
Directly Interdependent Libraries

Are these two repositories related? Yes!

jsTableBuilderViews is the high-level table grid & form builder framework. It relies directly on ks-web-components to render individual custom HTML elements (such as <ks-table-cell-content-common>) inside every table cell.

Core Dependency Low-Level

ks-web-components

The atomic component library and design system token engine. Handles individual inputs, formatted text, buttons, and cell validation.

  • ✓ Main Element: <ks-table-cell-content-common>
  • ✓ Scope: Single cell level (<td> / <th>)
  • ✓ Styles: Tailwind JSON presets (PREDEFINED_TEXT_CLASSES)
Role: Atomic Building Block (Bricks)
Framework Builder High-Level

jsTableBuilderViews

The layout orchestrator framework. Manages entire table structures, headers, footers, sorting, state management, and vertical views.

  • ✓ Main Engine: TableBuilder class
  • ✓ Scope: Full Grid (<table>) & Vertical Views
  • ✓ Features: State, sorting, filtering, column visibility
Role: Grid Architect & Orchestrator (Building)

System Execution Flow

1

JSON Config

Developer passes table data rows, column keys, and options.

2

TableBuilder

Generates table layout, headers, footers, and view structures.

3

Web Component

Embeds cell elements to render inputs, text, or buttons.

4

Rendered DOM

Applies Tailwind classes and displays the final interactive UI.

Code Integration Example

HTML / ES Module

Always import ks-web-components.js first before initializing TableBuilder: 

<!-- 1. Load the core web component dependency FIRST -->
<script src="https://keshavsoft.github.io/ks-web-components/dist/v12/ks-web-components.js" type="module"></script>

<!-- 2. Import and use TableBuilder from jsTableBuilderViews SECOND -->
<script type="module">
    import { TableBuilder } from "https://keshavsoft.github.io/jsTableBuilderViews/renderStart.js";

    const builder = new TableBuilder({
        htmlId: "app",
        data: [{ id: 1, item: "Laptop" }],
        columns: [{ dataKey: "item", header: "Item Name" }],
        views: [{ rendererType: "table" }]
    });

    await builder.build();
</script>
