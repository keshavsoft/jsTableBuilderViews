Global Search Guide

TableBuilder provides multi-column Global Search functionality that allows users to search for any string across all visible columns in the data grid simultaneously.

1. Global Search Overview

Global search checks all visible column data attributes for each row and retains rows where at least one cell contains the search query substring (case-insensitive).

// Example: Searching for "Electronics" queries all columns
tableBuilder.setGlobalSearch("Electronics");

2. How It Works Under The Hood

Global search relies on a multi-column filtering algorithm inside renderStart/dataFuncs/searchUtils.js:

  • Search Algorithm (searchUtils.js): Iterates over dataStore.columns and tests each row value using substring matching:
    row[col.dataKey].toString().toLowerCase().includes(query)
  • Toolbar Component (buildTable/index.js): Renders the search toolbar containing the input field, search button, clear button, and total row badge.
  • State Linkage (TableBuilder.js): Triggers table re-rendering (refreshTables()) whenever the search query is updated.

3. Results & Serial Re-sequencing

When global search filters data, any active Serial Number column (#) is automatically re-sequenced (1, 2, 3...) for the displayed result set.
