Configuration Schema & CDN Knowledge

How to pull configuration knowledge directly from the CDN library without writing custom JSON from scratch.

⭐ Core Architectural Concept

Pulling Configuration Knowledge Directly from CDN

Developers do not need to write configuration JSON from scratch or invent custom structures. The CDN library (TableBuilder) owns the authoritative schema knowledge and exports static methods to pull valid configuration objects at runtime:

TableBuilder.sampleConfig()

Pulls the official, fully valid sample configuration object template directly from the CDN library.

TableBuilder.describe()

Pulls the schema description metadata, required input parameters, and view constraints.

Code Example: Using CDN Knowledge when config.json does not exist

// 1. Import TableBuilder from CDN
import { TableBuilder } from "https://keshavsoft.github.io/jsTableBuilderViews/renderStart.js";

// 2. Pull valid configuration template directly from CDN
const config = TableBuilder.sampleConfig();

// 3. Attach your raw data array to the CDN config object
config.data = rawDataArray;
config.htmlId = "table-root";

// 4. Instantiate and render TableBuilder
const builder = new TableBuilder(config);
await builder.build();

The Root Object Structure

{
  "htmlId": "table-root",
  "data": [...],
  "columns": [...],
  "views": [...]
}
  • htmlId (String): The ID of the DOM element where the app will be rendered.
  • data (Array): An array of JSON objects containing raw data. The engine flattens nested keys automatically.
  • columns (Array): Defines schema for mapping data attributes to display headers, cell width, sorting, cell styling themes, and input control types (`controlType`).
  • views (Array): Defines layout renderers to execute (e.g. `rendererType: "table"` vs `rendererType: "vertical"`).

The Columns Array Schema

Each object in the `columns` array maps a flattened data key to display properties and input controls.

{
  "dataKey": "details.stockitemname",
  "header": "Stock Item Name",
  "options": {
      "sortable": true,
      "width": "150px",
      "table": {
          "tbody": { "theme": "table.cell.primary" },
          "tfoot": { "inputsRow": { "showInput": true, "controlType": "select" } }
      }
  }
}
