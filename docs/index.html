jsTableBuilderViews

A JSON-driven JavaScript UI library for building data tables, vertical forms, dynamic filtering, and configurable views.

🚀 Get Started ⚙️ Configuration

Quick Understanding

What does this repository provide?

jsTableBuilderViews converts configuration and application data into reusable UI views. The documentation below explains the repository from the basic concept to advanced configuration.

📊

Data

Provide your application data as JavaScript objects or arrays.

⚙️

Configuration

Define columns, options, forms, filters, and views through configuration.

🖥️

Renderer

TableBuilder uses the selected renderer to generate the UI.
