NPM Usage

How to use KeshavSoft TableBuilder with NPM.

Scaffolding a New Project

The easiest way to get started is to use the CLI tool to scaffold the necessary components into your project directory.

npx table-builder-views init

This command will:

  • Create the renderStart and webComponents folders.
  • Copy renderStart.js.
  • Scaffold a starter index.html.

CLI Commands

  • npx table-builder-views help

    Displays the help message and available options.

  • npx table-builder-views init

    Initializes the components and files needed to run TableBuilder.
