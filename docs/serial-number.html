Serial Number Column Guide

TableBuilder provides built-in support for displaying a dynamic Serial Number (#) column as the first column in your data table.

1. Enabling Serial Numbers via Configuration

You can enable the serial number column by adding "showSerialNo": true directly to your root configuration object or inside tableOptions.

{
  "htmlId": "table-root",
  "showSerialNo": true,
  "data": [
    { "name": "Item A", "category": "Electronics" },
    { "name": "Item B", "category": "Books" }
  ],
  "columns": [
    { "header": "Item Name", "dataKey": "name" },
    { "header": "Category", "dataKey": "category" }
  ],
  "views": [
    { "rendererType": "table" }
  ]
}

2. How It Works Under The Hood

The serial number feature works through a clean 3-step pipeline inside the library engine:

  • Config Flag Extraction (TableBuilder.js & setupDataStore.js): The constructor captures showSerialNo and passes it to the data initialization pipeline.
  • Column Header Prepending (prepareColumns.js): When showSerialNo is true, the engine automatically prepends a column definition at Index 0:
    { "header": "#", "dataKey": "$serial", "options": { "width": "60px", "align": "center" } }
  • Sequential Index Mapping (prepareData.js): Each data row is mapped to include $serial = index + 1.

3. Dynamic Re-sequencing

Whenever table data is searched or filtered, the engine automatically re-calculates $serial = 1, 2, 3... for the displayed matching rows so that serial numbers always count sequentially starting from 1.
