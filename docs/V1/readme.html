KeshavSoft jsTableBuilderViews

A lightweight, declarative Javascript UI library for generating complex data tables, vertical forms, and dynamic data filtering using a JSON-driven configuration approach.

Key Features

  • Declarative Configuration: Define your UI using a simple JSON structure.
  • Multiple Renderers: Render data as interactive data grids (`table`) or input forms (`vertical`).
  • Dynamic Filtering: Built-in state management for dynamically filtering tables without destroying DOM nodes.
  • Web Components Integration: Easily embed custom form inputs inside table cells using ``.
  • CDN Knowledge Discovery: Call `TableBuilder.sampleConfig()` to pull valid sample configurations directly from CDN.

CLI Scaffolding Command

npx table-builder-views init

Scaffolds `./renderStart/` (engine) and `./webComponents/` (UI elements & Tailwind tokens) into your local project root.
