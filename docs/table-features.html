Table Features Guide

This guide provides complete, step-by-step instructions and code examples for implementing Serial Numbers, Global Search, and Column-wise Filters in your TableBuilder applications.

🚀 Complete Working Example

Copy and paste this minimal snippet into an HTML file to initialize TableBuilder with all features enabled:

<!DOCTYPE html>
<html lang="en">
<head>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8">
    <!-- Target DOM Container -->
    <div id="table-root"></div>

    <script type="module">
        import { TableBuilder } from './dist/v6/renderStart.js';

        const config = {
            htmlId: "table-root",
            showSerialNo: true, // Enables # / $serial column
            data: [
                { id: 101, name: "Laptop", category: "Electronics", price: 1200 },
                { id: 102, name: "Keyboard", category: "Electronics", price: 75 },
                { id: 103, name: "Novel", category: "Books", price: 20 }
            ],
            columns: [
                { header: "ID", dataKey: "id" },
                { header: "Item Name", dataKey: "name" },
                { header: "Category", dataKey: "category" },
                { header: "Price ($)", dataKey: "price" }
            ],
            views: [
                { rendererType: "table" }
            ]
        };

        // Initialize TableBuilder Engine
        const instance = new TableBuilder(config);
    </script>
</body>
</html>

1. Serial Number Column (`#` / `$serial`)

Displays an automatic, sequential index column as the very first column in your data grid.

How to Enable:

Add showSerialNo: true to your root config JSON or constructor options.

Technical Execution Details:

  • prepareColumns.js: Detects flag and automatically prepends column definition { header: "#", dataKey: "$serial" } at Index 0.
  • prepareData.js: Maps each row item to include $serial = index + 1.
  • Dynamic Re-indexing: When rows are filtered or searched, TableBuilder automatically re-sequences $serial = 1, 2, 3... for all displayed rows.

2. Global Search Toolbar

Performs case-insensitive substring searching across all visible data columns simultaneously.

Toolbar Interface:

TableBuilder automatically renders a top toolbar containing an input box, Search button, Clear button, and a badge displaying matching row counts.

Programmatic API Method:

// Filters table to rows containing "Electronics" in any column
instance.setGlobalSearch("Electronics");

Technical Execution Details:

  • searchUtils.js: Implements processSearch() which tests row attributes against dataStore.columns.
  • State Management: Integrates with applyAllFilters() to maintain search state across table refreshes.

3. Individual Column-wise Search Filters

Renders dedicated search input fields under each column header inside <thead> for column-specific filtering.

Programmatic API Method:

// Filters specific column by dataKey
instance.setColumnFilter("category", "Books");

// Clear all active column and global search filters
instance.clearAllFilters();

Technical Execution Details:

  • TableHeader.js: buildColumnFilterRow() appends a second header row containing column input fields.
  • Multi-Column AND Logic: Column filters evaluate concurrently. Items must satisfy all active column criteria to be displayed.

📖 API Reference Summary

Method / Option Type / Params Description
showSerialNo Boolean Enables automatic `#` ($serial) column at Index 0.
setGlobalSearch(query) String Filters table data across all visible columns.
setColumnFilter(key, val) String, String Applies substring filter to a specific column key.
clearAllFilters() None Clears global search & column input filters and resets data.
