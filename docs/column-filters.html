Individual Column Filters Guide

TableBuilder supports column-specific searching, enabling users to filter data by individual attributes independently or in combination.

1. Column Filters Overview

Filter input boxes sit inside the header row (<thead>) directly beneath each column title header.

// Example: Programmatically filtering by column dataKey
tableBuilder.setColumnFilter("category", "Electronics");
tableBuilder.setColumnFilter("vouchernumber", "1024");

2. How It Works Under The Hood

Individual column filtering consists of a dedicated header component and multi-column evaluation logic:

  • Filter Row Component (TableHeader.js): buildColumnFilterRow() appends a second <tr class="ks-column-filter-row"> inside <thead>, rendering input elements for each data column.
  • Input Listener: Each cell input triggers an oninput event callback bound to setColumnFilter(col.dataKey, input.value).
  • Multi-Column AND Logic (TableBuilder.js): Column filters evaluate concurrently. Row items must satisfy all active column queries simultaneously to be included in the results.

3. Filter Concurrency & Resetting

Column-wise filters operate concurrently with Global Search and vertical form filters. Calling clearAllFilters() clears all column inputs and restores the original dataset.
